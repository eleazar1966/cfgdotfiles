         MANUAL DE NIRI - ARQUITECTURA COMPLETA
=============================================================================

1. NAVEGACIÓN Y TECLADO
  • Mod + H / L         : Columna Izquierda / Derecha
  • Mod + J / K         : Ventana Abajo / Arriba
  • Mod + Space         : Alternar teclado (US/ES)
  • Mod + Home / End    : Inicio / Fin cinta

2. REORGANIZACIÓN
  • Mod + Shift + H / L : Desplazar columna completa
  • Mod + Shift + J / K : Reordenar ventana verticalmente

3. OPERACIONES DE COLUMNA
  • Mod + [ / ]         : Integra / Expulsa ventana
  • Mod + , / .         : Integración inteligente
  • Mod + W             : Alternar columnas / pestañas

4. GEOMETRÍA Y ESCALADO
  • Mod + R             : Ciclar anchos (33%, 50%, 66%)
  • Mod + F             : Maximizar columna
  • Mod + Shift + F     : Pantalla completa
  • Mod + C             : Centrar columna
  • Mod + +/-           : Ajustar dimensiones

5. ESPACIOS DE TRABAJO
  • Mod + U / I         : Navegar espacios
  • Mod + 1-9           : Saltar a espacio
  • Mod + Shift + 1-9   : Mover a espacio

6. MULTIMEDIA Y AUTOMATIZACIÓN
  • Mod + M             : Entorno musical (MOCP + CAVA)
  • Mod + Shift + M     : Cerrar música
  • Mod + Y             : Gestor multimedia (yt-x)
  • Mod + N             : Silencio micrófono
  • Mod + G             : Grabar video

7. SEGURIDAD Y CIERRE
  • Mod + Q             : Cerrar ventana
  • Mod + Shift + P     : Apagar monitor
